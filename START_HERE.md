# 🚀 START HERE

## ONE SIMPLE STEP

1. Open Supabase SQL Editor: https://supabase.com/dashboard/project/fpqmnfunfpkvdrxfazgj/editor
2. Open file: `ONE_COMPLETE_SETUP.sql`
3. Copy ALL of it
4. Paste in SQL Editor
5. Click RUN
6. Sign in to your app: http://localhost:5173
7. Go to `/profile` and change your role to 'admin'
8. Done!
